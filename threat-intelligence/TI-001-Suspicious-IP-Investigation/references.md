## Future Intelligence Sources

The workflow can be extended with external intelligence sources such as:

- IP reputation services
- WHOIS/RDAP
- ASN databases
- Passive DNS
- Malware intelligence feeds
- URL and domain reputation services

## Analyst Note

External intelligence should be treated as supporting evidence.

An IOC should not be classified as malicious based on a single reputation source without considering context and corroborating evidence.
