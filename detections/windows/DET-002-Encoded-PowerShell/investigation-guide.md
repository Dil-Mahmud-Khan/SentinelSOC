# Investigation Guide

## Alert Summary

An alert indicating that PowerShell executed a Base64-encoded command.

---

## Investigation Steps

### Step 1 - Validate the Alert

- Confirm the alert is generated by Rule ID 100200.
- Record the alert timestamp.
- Identify the affected host.

---

### Step 2 - Identify the User

Collect:

- Username
- Hostname
- Source IP (if available)
- Logon Session

---

### Step 3 - Review the Process

Verify:

- Process Name
- Parent Process
- Command Line
- Process ID
- Parent Process ID

---

### Step 4 - Decode the PowerShell Command

If possible:

- Extract the Base64 string.
- Decode the command.
- Determine its purpose.

---

### Step 5 - Check for Malicious Activity

Look for:

- Network connections
- File downloads
- Registry modifications
- Scheduled tasks
- New services
- Child processes

---

### Step 6 - Determine Impact

Identify:

- Persistence
- Credential access
- Lateral movement
- Data exfiltration

---

### Step 7 - Analyst Decision

Classify the event as:

- True Positive
- Benign Administrative Activity
- False Positive

Document the justification.
