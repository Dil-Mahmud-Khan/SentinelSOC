# SentinelSOC Engineering Standards

Every detection in SentinelSOC must include:

- A clear explanation of why the detection was created.
- MITRE ATT&CK mapping.
- Detection logic.
- Custom Wazuh rule (when applicable).
- Sigma rule (when applicable).
- Testing procedure.
- Investigation guide.
- Response playbook.
- Validation checklist.
- False positive analysis.
- Detection tuning recommendations.
- Lessons learned after validation.

A detection is only considered **Complete** after it has been successfully validated in the lab and supporting evidence (logs and screenshots) has been documented.
