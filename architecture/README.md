# SentinelSOC Architecture

## Purpose

This directory contains the architecture documentation for SentinelSOC.

The architecture is designed to simulate a modern enterprise Security Operations Center (SOC) using open-source technologies. It illustrates how security telemetry is collected, processed, analyzed, and presented to analysts.

Rather than focusing only on deployment, the architecture emphasizes the complete detection engineering lifecycle—from endpoint telemetry generation to detection, investigation, incident response, and validation.

## Design Principles

- Modular architecture
- Detection-first design
- Separation of infrastructure and detection logic
- Reproducible lab environment
- MITRE ATT&CK aligned
- Enterprise-oriented documentation
